# Bundled Android presentation resources

Retrieved 28 October 2026 from official upstream repositories. Font files are original variable-font TTFs, loaded directly from res/font with Compose FontVariation on Android26+. No downloadable-font provider or runtime network request is used.

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans — SIL Open Font License1.1, preserved in dm-sans-OFL.txt.
- Fraunces: https://github.com/google/fonts/tree/main/ofl/fraunces — SIL Open Font License1.1, preserved in fraunces-OFL.txt.
- Material Symbols Rounded: https://github.com/google/material-design-icons/tree/master/symbols/web — Apache License2.0, preserved in material-symbols-APACHE.txt. Original SVG path geometry is translated from viewport0 -960 960 960 into native VectorDrawable XML by a +960Y group transform; no glyph artwork is redrawn.
- Protective Embrace: user-approved VITALINK arc/seed geometry, preserved as a native VectorDrawable. Forest #164C3F, pink #E9A4B7, rounded caps and joins.

Dribbble references remain outside the application. No reference photographs, fetus artwork, logos or proprietary icons are embedded in the APK.
