## Application interpretation

- Dashboard: clear greeting, one dominant action, organized sections and a restrained persistent navigation bar.
- Maternal editorial: rounded geometric functional typography, strong editorial headings, careful grouping and a selective pink accent. No reference photography or consumer pregnancy widgets are carried over.
- Minimal spacing: generous margins, sparse line icons, large readable values, clean lists and distinct sections.
- User-specified brand takes precedence over reference colors: white canvas, #164C3F forest, #E9A4B7 pink, #252B28 ink, #E5E7EB borders. Clinical urgency uses separate accessible semantic colors.
